# Test 3 — Dialogues style japonais

Textes de BOURG-EN-VOL et des 4 maisons réécrits avec une touche japonaise (toujours en français).

- **Honorifiques automatiques** : le code `{KUN}` (prévu par Game Freak pour la version japonaise, vide en VF) est réactivé → « -kun » si le joueur est un garçon, « -chan » si c'est une fille. Ça marche dans tout le jeu.
- **Expressions** : Okaeri, Itterasshai, Ara!, Hayaku!, Sugoi, Ganbatte, Yoroshiku, Gomen, Zannen, Shimatta…
- **Décor cité** : cerisiers, torii, tatamis, kotatsu, kamidana, horloge à balancier, bambous, jidaigeki à la télé, zori.
- Toutes les lignes ont été mesurées au pixel près avec la police du jeu (pire cas : nom de 7 lettres + « -chan »).

Dans ce fichier, [JOUEUR] = nom du joueur, « -kun » devient « -chan » pour une fille.
